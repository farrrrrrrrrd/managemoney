# Local Project Rules & Engineering Standards

Proyek ini mematuhi standar Zero AI-Slop dan Clean Architecture Antigravity 2.0.

- **Zero Placeholders:** Dilarang menggunakan placeholder `// TODO` atau kode setengah jadi.
- **Surgical Edits:** Ubah hanya baris yang relevan; jaga gaya kode dan konvensi penamaan repo ini.
- **Verification:** Selalu jalankan build / test lokal sebelum menyatakan tugas selesai.
- **Model Policy:** Subagent wajib menggunakan `Model: "inherit"`.
